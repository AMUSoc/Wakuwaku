# 自製一隻桌寵

這份是照著程式碼寫的規格（`src/pet/sprite.js`、`src/pet/pet.js`、`src/pet/island.js`、`src-tauri/src/data.rs`），並用內建的 `pets/claude-chan/` 對過。圖集的格式和 [codex-pets.net](https://codex-pets.net) 的 Codex pet v2 相同，所以那裡下載的寵物、Codex 自己的寵物都能直接用；自己畫的照這份做也一樣。

一隻寵物就是一個資料夾，裡面兩個檔案：

```
<寵物資料夾>/<id>/
  spritesheet.webp   圖集：1536×2288，8 欄 × 11 列，每格 192×208，透明背景
  pet.json           名字、作者、圖集版本
```

## 1. 圖集

| 項目 | 規格 |
| --- | --- |
| 檔名 | 一定要叫 `spritesheet.webp`（沒有這個檔的資料夾會被跳過；`pet.json` 的 `spritesheetPath` 不會被讀） |
| 格式 | WebP，RGBA，背景全透明。建議用無損（lossless）；邊緣可以有半透明（內建那隻就有反鋸齒的半透明邊） |
| 整張大小 | **剛好 1536 × 2288 px**（v2）。不能多也不能少：桌面上的她把整張圖拉成 1536×2288 的比例來切格子，島裡則用原尺寸切，大小不對兩邊都會錯位 |
| 格子 | 8 欄 × 11 列，每格 **192 寬 × 208 高**，格子之間沒有間距、沒有外框 |
| 座標 | 第 r 列第 c 欄（都從 0 算）的格子，左上角在 `(c × 192, r × 208)` |
| 每列的幀 | 從第 0 欄開始往右連續放；用不到的格子留**全透明** |

### 每一列放什麼

| 列 | 名稱（codex-pets.net） | 幀數 | 每幀 | 一輪 | 什麼時候出現 |
| --- | --- | --- | --- | --- | --- |
| 0 | `idle` 待機 | 6 | 260 ms | 1.56 s | 空閒：播一輪後停在第 0 幀 4 秒，再播一輪 |
| 1 | `running-right` 往右跑 | 8 | 110 ms | 0.88 s | 空閒時往右走、被往右拖 |
| 2 | `running-left` 往左跑 | 8 | 110 ms | 0.88 s | 空閒時往左走、被往左拖 |
| 3 | `waving` 揮手 | 4 | 180 ms | 0.72 s | 這一輪做完（done，循環播）；新工作階段開始時揮手（播 2 輪） |
| 4 | `jumping` 跳 | 5 | 130 ms | 0.65 s | Claude Code 的 TaskCompleted（播 1 輪）；從島裡被拉出來時 |
| 5 | `failed` 失敗 | 8 | 160 ms | 1.28 s | 出錯（error，循環播）；工具失敗（播 1 輪） |
| 6 | `waiting` 等你 | 6 | 200 ms | 1.2 s | 等你確認（waiting） |
| 7 | `running` 工作中 | 6 | 140 ms | 0.84 s | 工作中（working） |
| 8 | `review` 改好了 | 6 | 180 ms | 1.08 s | 改了檔案的這一輪結束（review） |
| 9 | 注視方向 0–7 | 8 | — | — | 空閒時眼睛跟著游標、東張西望（見下面） |
| 10 | 注視方向 8–15 | 8 | — | — | 同上 |

幀數和速度是寫死的（`sprite.js` 的 `CLIPS`），多畫的幀不會播，少畫的格子會播出空白。

畫的時候要注意：

- **每列的第 0 幀要是那個動作的代表姿勢。** 沒人在用電腦時（鍵盤滑鼠一陣子沒動），她會停在目前心情那一列的第 0 幀；待機每一輪之間也停在 `idle` 的第 0 幀 4 秒，這是她一天裡最常見的樣子。
- **循環的列要首尾相接**：`idle`、`running-right/left`、`waving`、`failed`、`waiting`、`running`、`review` 都會從最後一幀直接接回第 0 幀。
- `running-right` 和 `running-left` 是兩列各自畫的，不會自動鏡像；左右不對稱的角色（拿東西的手、側髮）兩邊都要畫。
- `jumping` 是一次性的動作，從站姿起跳、落回站姿；內建那隻在空中的幀腳會離開格子底部（往上移），這樣看起來才是跳。

### 16 個注視方向（第 9、10 列）

第 i 個方向（i = 0–15）放在第 `9 + floor(i / 8)` 列、第 `i % 8` 欄。0 是正上方，之後每一個**順時針**轉 22.5°。「右」是螢幕的右邊（也就是圖上的右邊，不是角色自己的右手邊）。

| i | 列, 欄 | 角度 | 看向 | | i | 列, 欄 | 角度 | 看向 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 0 | 9, 0 | 0° | 正上 | | 8 | 10, 0 | 180° | 正下 |
| 1 | 9, 1 | 22.5° | 上偏右 | | 9 | 10, 1 | 202.5° | 下偏左 |
| 2 | 9, 2 | 45° | 右上 | | 10 | 10, 2 | 225° | 左下 |
| 3 | 9, 3 | 67.5° | 右偏上 | | 11 | 10, 3 | 247.5° | 左偏下 |
| 4 | 9, 4 | 90° | 正右 | | 12 | 10, 4 | 270° | 正左 |
| 5 | 9, 5 | 112.5° | 右偏下 | | 13 | 10, 5 | 292.5° | 左偏上 |
| 6 | 9, 6 | 135° | 右下 | | 14 | 10, 6 | 315° | 左上 |
| 7 | 9, 7 | 157.5° | 下偏右 | | 15 | 10, 7 | 337.5° | 上偏左 |

這 16 張是靜止的單張，不播動畫：游標在她附近（40–900 px 內）移動時，她停在最接近游標方向的那一張，游標停下後 1.8 秒回到待機；沒人動游標時她偶爾自己往隨機 2–3 個方向各看 0.7 秒。只在空閒時看。這 16 張的身體姿勢最好和 `idle` 第 0 幀一樣，只有頭、眼睛（可以加一點上身）轉向，換來換去才不會跳。

（`sprite.js` 的 `lookCell`：`角度 = atan2(dx, −dy)`，螢幕座標 y 向下，四捨五入到最近的一檔。）

### 角色在格子裡的位置

所有列都用**同一個基準**：同樣的腳底高度、同樣的水平中心，換動作時她才不會在原地跳動。內建那隻量起來是這樣，照著做最保險：

| | 內建 claude-chan |
| --- | --- |
| 腳底 | y ≈ 204（離格子底 4 px），每一列都一樣（跳的那幾幀除外） |
| 頭頂 | y ≈ 4 |
| 左右 | x ≈ 15–174，大致置中（格子中線 x = 96） |

**頭和上半身要在格子的上方中間。** 她走出島到桌面上時，島裡會留一張她的圓形小頭像（24 px 和 48 px 兩種，播她目前心情那一列的動畫），頭像只裁格子的這一塊：

```
x：39 – 153（中間 114 px）
y：10 – 120
```

臉落在這一塊裡頭像才看得到臉。所有心情的列（0、3、5、6、7、8）都會出現在頭像裡。

### 會被縮成多大

圖用 192×208 原尺寸畫，程式會縮小顯示，所以細線和小字縮小後會糊掉，輪廓要清楚：

| 顯示在哪 | 縮放 | 大約多大（CSS px） |
| --- | --- | --- |
| 桌面上的她：小 / 中（預設）/ 大 | 0.4 / 0.55 / 0.75 | 77×83 / 106×114 / 144×156 |
| 展開的島裡站著的她 | 0.5 | 96×104 |
| 島裡的頭像（她在桌面上時） | 只裁上方中間 | 24 px、48 px 的圓 |
| 設定頁的縮圖 | 36–52 px 寬 | — |

（螢幕縮放 125% 時實際像素再乘 1.25。）

### 舊的 v1 圖集

1536 × 1872、9 列（只有第 0–8 列，沒有注視方向）。`pet.json` 的 `spriteVersionNumber` 不是 `2` 就當成 v1：她不會東張西望、不跟游標。自己畫的話建議直接做 v2。**v2 的圖千萬不要漏寫 `"spriteVersionNumber": 2`**，否則桌面上的她會用 v1 的高度切格子，整張圖被壓扁。

## 2. pet.json

UTF-8 的 JSON。程式只讀三個欄位，其他欄位是給人和 codex-pets.net 看的，可以照寫。

```json
{
  "id": "my-pet",
  "displayName": "我的寵物",
  "description": "一句介紹。",
  "author": "你的名字",
  "spritesheetPath": "spritesheet.webp",
  "spriteVersionNumber": 2,
  "kind": "person"
}
```

| 欄位 | 讀不讀 | 說明 |
| --- | --- | --- |
| `displayName` | 讀 | 設定頁、系統匣選單裡的名字。沒有就用資料夾名 |
| `author` | 讀 | 設定頁名字下面的小字 |
| `spriteVersionNumber` | 讀 | **`2`** = 11 列的 v2；其他（或沒寫）= 9 列的 v1 |
| `id` | 不讀 | 寵物真正的 id 是**資料夾名**；寫成一樣比較不會搞混 |
| `description`、`source`、`kind` | 不讀 | 照 codex-pets.net 的格式留著 |
| `spritesheetPath` | 不讀 | 圖集固定叫 `spritesheet.webp` |

沒有 `pet.json`（或寫壞了）也能用，名字就是資料夾名、當成 v1。

## 3. 放在哪裡

依這個順序找，**同一個 id 先找到的算數**，後面的同名寵物被忽略：

1. **她的資料夾裡的 `pets/`**：
   - 從原始碼建置、執行的（這個 fork 的用法）：`<專案>/data/pets/<id>/`
   - 下載的 exe：exe 旁邊的 `wakuwaku-data/pets/<id>/`
   - 測試時設了 `WAKUWAKU_USER_DATA`：`<那個資料夾>/pets/<id>/`
2. 建置它的那份原始碼的 `pets/`（`<專案>/pets/<id>/`，內建的 claude-chan 在這裡；只有在建置它的那台電腦上存在）
3. Codex 的寵物：`~/.codex/pets/<id>/`（`CODEX_HOME`），只讀不寫

資料夾名開頭是 `.` 的會被跳過（那是下載中的暫存）。

自己做的放第 1 個位置就好。新增一個寵物資料夾後，她會自己發現（看的是 `pets/` 資料夾的修改時間），在設定的「外觀」頁的寵物清單裡就能選。**換掉一隻已經在用的寵物的圖**時，資料夾本身沒有新增或刪除，請結束她再重新開，才會讀到新圖。

## 4. 每個 agent 一隻

設定的「外觀」頁，「已下載」的每一隻寵物下面有 Claude Code、Codex、Antigravity、Grok 四個小標籤：點一下，那個 agent 的工作階段就用這隻顯示，再點一下取消。下面的「各個 agent 的角色」列出四個 agent 現在用哪一隻，「用預設」改回預設。

島上顯示哪個工作階段，她就換成那個 agent 的角色（她走到桌面上時也一樣）；沒指定的、或指定的那隻被刪掉了，就用「正在使用」的那隻；沒有任何工作階段時也是「正在使用」的那隻。換角色時新圖集要先載入、解碼完才換上去，載入中還是顯示原本那隻，所以不會閃一下空白。

設定存在 `config.json` 的 `agentPets`，例如 `{ "codex": "my-pet", "grok": "owl" }`。

## 5. 用 tools/make_sheet.py 組圖

AI 繪圖產出的是一張一張的圖，用 `tools/make_sheet.py` 排成圖集（需要 Pillow：`pip install pillow`）：

```
frames/
  idle/           6 張
  running-right/  8 張
  running-left/   8 張
  waving/         4 張
  jumping/        5 張
  failed/         8 張
  waiting/        6 張
  running/        6 張
  review/         6 張
  look/           16 張，00.png = 正上方，順時針
```

每張 PNG 都要是 192×208、透明背景；同一個資料夾裡**照檔名排序**就是播放順序（建議 `00.png`、`01.png`……）。

```
python tools/make_sheet.py frames data/pets/my-pet/spritesheet.webp
```

張數或尺寸不對時它會說是哪一個資料夾、哪一張，不會產出圖集。它輸出無損 WebP，空的格子保持全透明。（用內建 claude-chan 拆開再組回去測過：除了原圖 idle 列多畫、程式不播的第 7 格，像素完全一樣。）
