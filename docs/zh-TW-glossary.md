# 繁體中文（台灣）用詞對照表

介面的 `zh-TW` 是照這份表從簡體 `zh` 翻過來的（`src/shared/i18n.js`、`src-tauri/src/i18n.rs`、`src-tauri/src/fetch.rs` 的錯誤訊息）。之後新增字串時照這份翻，表裡沒有的詞就照台灣的慣用說法，**不要簡轉繁直接轉**，並補進這份表。

## 規則

- `{name}`、`{n}`、`{tool}` 這類佔位符原樣保留，不翻、不改順序以外的東西；`<b>`、`<span class="mono">` 等標記也原樣保留（`test/i18n.test.js` 會檢查）。
- 產品名、指令、檔名、路徑不翻：Claude Code、Codex、Antigravity、Grok、hooks、settings.json、`/hooks`、PowerShell、agent、token、PR、issue、CI。
- 引號用「」（簡體字串裡的 “” 也改成「」），標點用全形。
- 語氣跟簡體版一樣口語、短；她是「她」。
- 新加的鍵三種語言（`zh`、`zh-TW`、`en`）都要有；`test/i18n.test.js` 會擋下缺的鍵、簡體字，以及下表左欄那些大陸用詞。
